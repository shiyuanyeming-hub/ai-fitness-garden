# 算法说明（计算版本 2026.10-v1）

所有系数在 `src/core/params.ts`。标注：
- **[依据]**：方向和大致量级有文献支持
- **[估计]**：产品规则，合理且透明，但**不是经过验证的生理常数**

本应用不测量肌肉实际受到的刺激，也不测量真实生理恢复。所有输出都是基于训练日志的估算。

## 1. 有效组数（Volume）

对每个**已确认**的组（`completedAt` 非空且有次数/时间/距离）：

```
有效组 = 组类型系数 × 努力系数(RIR) × 肌群贡献系数 × 侧别份额
```

| 项 | 取值 | 标注 |
|---|---|---|
| 组类型 | 正式 1，热身 0，递减组每段 0.5 | [估计] |
| 肌群贡献 | 主要 1.0，辅助≈0.5，稳定肌≈0.25（逐个动作可调） | 0.5 的「分数组」计法：[依据] Remmert/Pelland 等对肌肥大拟合最好；具体每个动作的值：[估计] |
| 努力（RIR，RPE 换算为 10−RPE） | RIR 0–3 → 1.0；4 → 0.75；5 → 0.5；≥6 → 0.25 | 越接近力竭肌肥大越好：[依据] Robinson 等 2024；分段值：[估计] |
| RIR 缺失 | 按 1.0 计算，**但恢复估计标注「可信度低」**，不把缺失值当作观测值 | [估计] |

**侧别份额（统计口径在各层一致）**

| 情况 | 份额 |
|---|---|
| 双侧组 → 分左右的肌群 | 左 1、右 1；肌群层取两侧平均 → 3 组仍是 3 组 |
| 单侧组 → 同侧肌群（same_side） | 该侧 1，另一侧 0（只练右侧侧平举只更新右肩） |
| 单侧组 → 不分左右的肌群（腹直肌、竖脊肌…） | 0.5（左右各一组 ≈ 一个双侧组）[估计] |
| 方向性组（向左/向右旋转）| 只记核心整体（center）0.5，**不生成左/右腹斜肌数据** [估计] |

**部位层**：每个动作对一个部位记「该部位肌群中最大的那个值」，再按动作和训练累加。卧推 3 组 = 胸部 3 组（不是上胸 + 中下胸 = 4.2）。

## 2. 恢复负担（Recovery Demand）与强度、努力的区分

- **Volume**：有效组数（上面）。
- **Intensity**：保存原始重量/次数/阻力形式。不同器械、不同阻力形式的重量**不互相比较**；辅助重量越大越轻松，不计为外部负重。
- **Effort**：RIR/RPE。
- **Recovery demand** = 有效组 × 力竭系数：RIR≤0 ×1.3，RIR 1 ×1.15，RIR 2–3 ×1.0，≥4 ×0.8。
  [依据] 力竭训练比相同训练量的非力竭训练恢复更慢，差异在训练后 24–48 小时明显（Morán-Navarro 等 2017）；具体倍数 [估计]。

四个量分开保存/展示，没有合成一个不透明总分。

## 3. 恢复模型

每个肌群的每一侧分别计算：

```
残余疲劳 F(t) = Σ_i demand_i · exp(−(t − t_i) / τ)          （近 14 天的所有刺激累加，不覆盖）
τ = 17.3h × 肌群大小系数(大 1.15 / 中 1.0 / 小 0.85) × 个人系数 × 今日状态系数
预计可训练：F ≤ θ = 0.25
预计可训练时间 = now + τ · ln(F/θ)
准备度% = ln(F_peak/F) / ln(F_peak/θ)   （从最近一次刺激到预计可训练的时间进度）
```

标定（[估计]）：约 4 个有效组 ≈ 48 小时，8 组 ≈ 60 小时，2 组 ≈ 36 小时，1 组（例如辅助肌群）≈ 24 小时。这避免了「所有肌群固定 48 小时」。

| 状态 | 条件 |
|---|---|
| 恢复中 | 准备度 < 60% |
| 逐渐恢复 | 准备度 ≥ 60% |
| 预计可训练 | F ≤ θ |
| 需要关注 | 报告疼痛或明显酸痛；单次 ≥12 有效组；近 7 天 ≥22 有效组；连续 ≥3 天对同一肌群 ≥3 组；连续 ≥3 天自评疲劳（且未恢复）[全部为估计] |

**主观反馈**（36 小时内有效，[估计]）

- 今日精神：一般 τ×1.05，疲劳 ×1.15；睡眠：一般 ×1.03，较差 ×1.10
- 某肌群酸痛：轻微 +0.4、明显 +1.2 的额外残余（随时间同样衰减）
- 酸痛不等于训练效果，只作为恢复估计的输入。

**个人化**：按时间顺序回看每次肌群酸痛反馈——模型当时认为「已恢复」但你报告「明显酸痛」→ 该肌群 τ +5%；模型认为「恢复中」但你报告「无酸痛」→ −2.5%。范围 0.8–1.4。这是个人启发式，不是已验证的模型。

**倒计时**：在手机本地每秒/每 30 秒重新计算，不请求服务器。修改/删除/补录任何训练后整体重算。

## 4. 每周目标与 3 个月计划

计划把目标周期平均分成三段：适应期 → 累积期 → 提升期。

| 每周有效组（初级） | 适应期 | 累积期 | 提升期 |
|---|---|---|---|
| 重点部位 | 6–9 | 8–12 | 10–14 |
| 维持部位 | 3–5 | 4–6 | 4–6 |
| 暂不优先 | 0 | 0 | 0 |

[依据] 每周约 10 组以上的肌肥大效果优于更低训练量（Schoenfeld 等 2017），之后边际收益递减（Pelland 等 2024）；初学者从较低训练量开始（ACSM 2009：每个动作 1–3 组、每周 2–3 天）。每周频率 2 次优于 1 次（Schoenfeld 等 2016）。各阶段具体区间：[估计]。中级/高级的区间见 `params.ts`。

单次处方（初级）：复合动作 3 组 × 8–12 次、RIR 2–3、休息 120 秒；孤立动作 3 组 × 10–15 次、RIR 1–3、休息 75 秒；核心 3 组 × 10–15 次、RIR 2–3、休息 60 秒。[依据] ACSM 2009 的新手区间；RIR 目标 [估计]。

## 5. 每日推荐（确定性）

1. 部位状态：看该部位关键肌群（例如肩部 = 前/中/后束）每一侧。全部已恢复 = 可训练；至少一半已恢复或最低准备度 ≥60% = 逐渐恢复；否则恢复中。卧推让前束疲劳时，不会封锁整个肩部。
2. 部位得分 = 恢复系数（可训练 1 / 逐渐恢复 0.35 / 恢复中 0）× 优先级（重点 3 / 维持 1.5）×（本周缺口 + 距上次训练天数）。「暂不优先」不推荐；本周已达上限的部位不推荐。
3. 时间预算 ≈ (每次分钟 − 8) / 3 组；最多 3 个部位；每部位本次分配 = ceil(本周缺口 / min(2, 本周剩余训练次数))，限制在 3–6 组（初级）。
4. 选动作：只用**当前健身房已登记器械**能做的动作（没登记时按常见商业健身房推断并提示）；排除你设定的动作；不超过训练水平难度；按动作模式槽位分配（例如背部：垂直拉 + 水平拉）；熟悉的动作加分（便于比较进步）；主要肌群仍在恢复的动作扣分，会额外训练其他疲劳肌群的动作扣分。≥4 组拆成 2 个动作、≥8 组拆成 3 个。
5. 推荐只是建议：你可以练任何部位。实际训练保存为事实，没做的推荐不算；下一次推荐按实际记录重算。每天第一次显示的推荐会保存下来，在历史中显示「推荐 vs 实际」。

## 6. 动作替换

候选必须在当前健身房可做、未被排除。得分 = 肌群向量余弦相似度（主要肌群权重最高）+ 同动作模式 0.2 + 适合水平 0.05 − 技术要求过高 0.3 − 每个会额外训练的疲劳肌群 0.15。相似度 < 0.45 的不列出。每个候选都给出原因（「同样主要训练背阔肌 · 动作模式相同 · 当前健身房有：辅助引体/臂屈伸机」）。

## 7. 渐进超负荷（双重渐进）

只与**同一动作、同一阻力形式、同一单位、同一台器械**（已知时）的历史比较。

| 上次表现 | 建议 |
|---|---|
| 没有历史 | 不编造重量：说明如何用热身组找到能完成目标次数上限、还剩 2–3 次的重量 |
| 所有正式组都达到次数上限，且平均 RIR ≥1（没填 RIR 时需要连续两次达到） | 加重：杠铃 +2.5kg，哑铃 +1/+2kg（换下一对），器械「+1 档」（不给具体数字），lb 单位 +5lb；辅助器械 → 减少一档辅助 |
| 达到上限但几乎没有余力 | 保持重量，再确认一次（不机械加重） |
| 有组低于下限 | 保持重量；连续两次低于下限 → 减约 10% |
| 其他 | 保持重量，每组争取多 1 次 |

同时识别「相同重量下次数提升」（例：40kg 8→10 次）。自重动作达到上限时建议增加难度（放慢离心、暂停、变式），不给加重数字。

## 8. 肌肉农场与成就

植物阶段只映射准备度（种子 <15%，发芽 <45%，生长 <75%，含苞 <100%，成熟 = 预计可训练）。再次训练 = 重新播种，所以多练不会长得更快。成就只奖励：连续 N 周达到每周训练天数、在重点部位「成熟」后再训练、同一器械上的进步次数——不奖励训练量或每天打卡。
